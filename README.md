# Climate Change Impact on Agricultural Land Suitability

This project analyzes the effects of climate change on agricultural land suitability using interpretable machine learning techniques. 
It focuses on Eurasia, a region facing unique environmental and socio-economic challenges, and provides predictive insights to support strategic resource allocation.

## Project Overview
- Predicts land degradation and irrigation shifts under different carbon emission scenarios.
- Achieves **86% accuracy** and **72% mean average precision** in multi-class land suitability classification.
- Highlights vulnerable regions in **Europe and Asia** for policy planning.
- Aligns with global efforts to mitigate food insecurity through data-driven decision-making.

## Technologies Used
- **Machine Learning**: Scikit-learn, TensorFlow
- **Web Framework**: Django
- **Visualization**: Matplotlib, Chart.js
- **Database**: MySQL
